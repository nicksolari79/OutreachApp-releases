# Outreach Manager

Download the latest version of Outreach Manager.

**➡ [Go to the latest release](../../releases/latest)**

## Which file do I download?

Download **one** file, for your computer:

| Your computer | Download this file |
|---|---|
| **Windows** (64-bit, Windows 10 or 11) | `Outreach-Manager-Setup-x.x.x.exe` |
| **Mac** (Apple Silicon: M1 or newer) | `Outreach-Manager-x.x.x.dmg` |
| **Linux** | `Outreach-Manager-x.x.x.AppImage` |

You don't need any of the other files. The `.yml` and `.blockmap` files are used by the app to check for updates, and the "Source code" links are added by GitHub automatically. They only contain this page, not the app.

## Installing

### Windows
1. Run `Outreach-Manager-Setup-x.x.x.exe`.
2. If Windows shows **"Windows protected your PC"**, click **More info**, then **Run anyway**.
3. Follow the installer's steps.

### Mac
1. Open the `.dmg` file and drag **Outreach Manager** into **Applications**.
2. If macOS says the app **"is damaged and can't be opened"**, open **Terminal** and run:

   xattr -cr "/Applications/Outreach Manager.app"

   Then open the app again.

Intel Macs aren't supported yet.

### Linux
1. Make the file executable: right-click it → **Properties** → **Permissions** → allow running as a program, or run `chmod +x Outreach-Manager-x.x.x.AppImage`.
2. Double-click it to open.

> These warnings appear because the app isn't code-signed yet. They're expected, and only appear the first time.

## Updates

Once installed, Outreach Manager checks for new versions on its own and asks before downloading anything. You can also check any time with the update button in the top-right corner of the Dashboard.

On a Mac, updates open this page so you can download the new version and install it the same way.

## User guide

Each release includes **`Outreach-Manager-User-Guide.pdf`**, a step-by-step guide to using the app. A copy is also installed with the app.

Your data is stored on your own computer, and it stays in place when you update.
